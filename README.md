## ▶️ Running Locally

### Option 1: Python HTTP Server
```bash
python -m http.server 8000
```
Then visit: `http://localhost:8000`

### Option 2: Node.js (npx serve)
```bash
npx serve .
```

### Option 3: VS Code Live Server
Right-click `index.html` and select **Open with Live Server**.
